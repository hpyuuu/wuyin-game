## 1. 代码交付

### 1.1 入口与核心逻辑

| 文件 | 职责 | 规模 |
|---|---|---|
| `assets/scripts/GameEntry.ts` | 入口、页面路由、输入分发、开局/结算/重开 | 约 800 行 |
| `assets/scripts/core/GameConfig.ts` | 全部可调参数 | 约 90 行 |
| `assets/scripts/core/ChartTypes.ts` | 谱面 / 判定数据结构 | 约 70 行 |
| `assets/scripts/core/ChartStore.ts` | 内置谱生成、玩家谱 CRUD、导入、加载 | 约 730 行 |
| `assets/scripts/core/AudioManager.ts` | 音频上下文、时钟、合成发声 | 约 600 行 |
| `assets/scripts/core/GameMain.ts` | 生成 / 位置 / 判定 / 计分 / 结算 | 约 400 行 |
| `assets/scripts/core/NotePool.ts` | 音符视图与对象池 | 约 220 行 |

### 1.2 界面模块

| 文件 | 职责 |
|---|---|
| `ui/Theme.ts` | 五色、字体、颜色工具 |
| `ui/Backdrop.ts` | 深色网格背景 |
| `ui/SceneBuilder.ts` | 轨道 / 判定线 / 键位 / 光效 / 布局计算 |
| `ui/MainMenu.ts` | 主菜单三卡片 |
| `ui/ChartSelect.ts` | 选谱列表（分页 + 难度筛选） |
| `ui/ChartEditor.ts` | 谱面编辑器（128 行网格） |
| `ui/FreePlay.ts` | 自由弹奏五弦 |
| `ui/HUD.ts` | 分数 / 连击 / 判定 / 结算 |
| `ui/PromoPage.ts` | 宣传内容页 |
| `ui/PressFeedback.ts` | 统一按压反馈 |

### 1.3 资源与工程配置

- `assets/main.scene`（唯一场景）
- `assets/resources/charts/demo.json`（示例谱面）
- `assets/resources/audio/tones/*.mp3`（C4 / F#4 / A4 钢琴采样，各约 14KB）
- `settings/v2/packages/*.json`（设计分辨率 720×1280 等）
- `tsconfig.json`、`package.json`、`.gitignore`

### 1.4 测试资产

- `tools/tests/test.js`：50 项单元测试
- `tools/tests/mock-cc/index.js`：Cocos 引擎最小替身
- `tools/tests/tsconfig.json`：测试专用编译配置
