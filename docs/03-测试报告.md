## 3. 单元测试结果

**50 项全部通过，0 失败。**

### 一、谱面解析与存储（11 项）
- normalizeChart 过滤非法 lane / 非数字 time / 非 Tap
- normalizeChart 按时间升序排序
- parseChartText 解析简谱文本
- parseChartText 拒绝空文本 / 无有效音符
- parseChartText 导入 JSON 时保留谱面自身 bpm
- loadChart 资源缺失时回退内置谱面
- saveCustomChart 覆盖已有玩家谱时保持同一 id
- 同一毫秒连续新建两份谱面不会互相覆盖
- deleteCustomChart 不删除内置谱
- listAllMetas 对残缺元信息补齐默认字段
- 内置旋律谱已收录且数据量合理（12 首）

### 二、判定与计分（9 项）
- 判定窗口边界：±40 / ±80 / ±120
- 超出 ±120ms 的点击不消耗音符
- 超窗未击打自动判 MISS 并计入统计
- MISS 的音符应播放下沉淡出动画后再回收
- 非法 lane 的音符在装载时被过滤，不会击穿对象池
- 非法 / 负数时间的音符不会污染结算
- 所有音符结束后延迟结算
- 连击与准确率计算
- restart 清空统计与活动音符

### 三、谱面编辑器（5 项）
- 编辑已有谱面后保存应沿用原 id
- open 遇到非法 notes 字段不应崩溃
- 点击网格最底部的不可见行不应写入音符
- 可见行点击可以正常增删音符
- open → buildChart 的时间轴往返一致

### 四、自由弹奏（2 项）
- 重新进入自由弹奏后首击必须发声（触点状态不残留）
- releaseTouch 清除该触点记录

### 五、选谱列表（5 项）
- 超出单页容量的自制谱可以通过分页访问
- 仅内置谱时按 6 条一页分页
- setPage 会对越界页码做钳制
- 难度筛选按等级过滤并重置分页
- 筛选后翻页越界会被钳制回第一页

### 六、HUD 与布局（2 项）
- HUD 隐藏时移出屏幕而不是切换 active（规避微信字形缓存丢失）
- 极端矮屏下判定线与轨道顶部不会交叉

### 七、宣传页（1 项）
- 宣传页收录视频知识点，且左侧文案纵向不重叠

### 八、音高与自动音符（5 项）
- 所有旋律谱的音符都带合法 MIDI，半音只作为自动音符
- 紫竹调 / 茉莉花 / 东方红的音高细节与参考谱一致
- normalizeChart 保留合法 MIDI，剔除非法音高
- 自动音符到点发声、不生成方块、不计入判定
- 同轨不同八度只改变外观，不改变轨道归属

### 九、分数系统（10 项）
- 计分：基础分 + 连击加成（PERFECT 100 / GREAT 65 / GOOD 30，连击 ×2，封顶 100）
- 连击加成上限 100，第 101 连击不再增长
- MISS 不加分、清空连击、保留最大连击峰值
- 同一音符重复点击不会重复计分
- 空气打（超窗口）不产生判定也不加分
- 结算快照与实时分数 / 准确率 / 最大连击完全一致
- 最高分：首次写入、低分不覆盖、高分覆盖
- 最高分：0 分不占记录，损坏 / 负数 / 非数字数据按无记录处理
- 结算页：5 位定长分数、顶部实时数据移出画面、BEST / NEW RECORD 正确展示
- 分数超过 5 位时不被截断

## 5. 本轮修复的缺陷

| # | 问题 | 根因 | 修复 |
|---|---|---|---|
| 1 | 旋律谱徵轨恒空、音符缺失 | 用 `'12345'.indexOf()` 映射，5 落到羽轨、6 返回 -1 被丢 | 改为显式映射表 |
| 2 | 时间戳出现 2666.666 | 浮点累加未取整 | 统一 `Math.round` |
| 3 | 编辑器保存生成副本 | `buildChart` 的 meta.id 硬编码空串 | 记住原 id |
| 4 | 单页时分页按钮文字残留 | label 挂在页面根节点 | 文字挂到按钮节点下 |
| 5 | 自由弹奏返回键失灵 | `onTouchEnd` 先处理琴弦收尾并 return | 先执行待处理点击 |
| 6 | 跨局残留上局 MISS 文字 | 未在新局清空判定标签 | 新增 `_resetJudge()` |
| 7 | 点击反馈比实际位置高约 139px | Canvas 中心与可见高度不一致 | `_syncCanvasSize()` + 相机反投影 |
| 8 | 音频初始化失败被永久缓存 | 失败的 Promise 未置空 | 失败时 `_initPromise = null` |
| 9 | 非法谱面击穿对象池 | 未校验 lane / time | load 阶段统一过滤 |
| 10 | MISS 音符瞬间消失 | 直接回收节点 | 改为下沉淡出动画后回收 |
| 11 | 结算页左上仍显示实时分数，与结算成绩同屏 | 顶部数据未随结算隐藏 | 顶部数据收进 `TopBar`，结算整体移出画面 |
| 12 | 结算分数只渲染出部分位数 | Label 无固定尺寸 + CHAR 缓存 | 固定 560×110 + SHRINK + 关闭字形缓存 |
| 13 | 分数没有持久化 | 只有谱面存储，成绩未落盘 | 新增 `ScoreStore`，按谱面记录最高分 |
| 14 | 结算详情无法核对判定总数 | 缺 TOTAL 字段 | 增加 `TOTAL 已判定 / 音符总数` |
