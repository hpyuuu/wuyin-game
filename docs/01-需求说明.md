# 需求说明（SRS）

> 项目：五音 · 五轨（微信小游戏）
> 版本：v1.0.0
> 文档状态：结项归档

---

## 1. 项目背景与目标

以中国传统五声音阶（宫、商、角、徵、羽 = 简谱 1 2 3 5 6）为核心，做一款**零美术素材、纯程序化表现**的微信小游戏：

- 玩法层：五条固定轨道的下落式节奏游戏
- 体验层：可自由拨动的五根琴弦，随手一按就好听
- 内容层：内置 12 首五声旋律谱，另有科普页讲清「三分损益」与五声音阶的由来

目标用户：对音乐游戏或国风内容感兴趣的轻度玩家。

---

## 2. 术语

| 术语 | 含义 |
|---|---|
| 五音 / 五声 | 宫、商、角、徵、羽，对应 MIDI 60 / 62 / 64 / 67 / 69 |
| 轨道（lane） | 0~4，从左到右依次为宫商角徵羽 |
| 判定窗口 | PERFECT ±40ms、GREAT ±80ms、GOOD ±120ms |
| auto 音符 | 谱面中的半音（4/7），到点自动发声，不下落、不判定 |
| 三分损益 | 以弦长 81 为宫，依次乘 2/3、4/3 得到其余四音 |

## 3. 功能需求

### FR-01 主菜单
- FR-01-1 三个入口卡片：节奏模式、自由弹奏、宣传内容
- FR-01-2 所有卡片具备统一的按下/抬起反馈（缩放 0.96，按下 80ms、抬起 140ms）

### FR-02 节奏模式
- FR-02-1 五条垂直轨道 + 底部判定线，音符自上而下匀速下落
- FR-02-2 按下轨道判定同轨最近音符，按偏差给出 PERFECT / GREAT / GOOD
- FR-02-3 音符超过 +120ms 未击打判 MISS，播放下沉淡出动画
- FR-02-4 实时 HUD：分数、连击、准确率、判定文字
- FR-02-5 结算页：总数、各档数量、最大连击、准确率、评级
- FR-02-6 支持重开与返回选谱
- FR-02-7 支持多点触控（多轨同时按下）

### FR-03 自由弹奏
- FR-03-1 五根可拨动琴弦，触点落在弦上即发声
- FR-03-2 弦有位移弯曲、光点、波纹反馈
- FR-03-3 同一触点拖动到另一根弦可继续发声；离开后重置
- FR-03-4 与节奏模式共用同一套音频引擎

### FR-04 宣传内容
- FR-04-1 展示五音色块（宫商角徵羽 + 简谱数字）
- FR-04-2 讲解三分损益：弦长 81 → 徵 54、商 72、羽 48、角 64
- FR-04-3 讲解 3 : 2 比例与波形重合的和谐原理
- FR-04-4 解释七声中「变徵」「变宫」因半音相邻刺耳，故只留五声
- FR-04-5 举例：吉他第一个音阶、《友谊地久天长》只用两个音
- FR-04-6 落到两种玩法的介绍

### FR-05 选谱
- FR-05-1 内置 12 首：3 首程序谱（初识 / 流云 / 疾风）+ 9 首旋律谱（紫竹调、茉莉花、东方红、金蛇狂舞、浏阳河、彩云追月、翠湖春晓、渔舟唱晚、赛马）
- FR-05-2 每页 6 条，支持上一页 / 下一页，页码越界自动钳制
- FR-05-3 难度筛选：全部 / EASY / NORMAL / HARD，筛选后回到第一页
- FR-05-4 自制谱可删除；内置谱不可删除
- FR-05-5 支持从剪贴板导入 JSON 谱面或简谱文本

### FR-06 谱面编辑器
- FR-06-1 128 行网格、五轨点选，点击增删音符
- FR-06-2 可设置名称、BPM、难度
- FR-06-3 保存为新谱或覆盖原谱（保持原 id）
- FR-06-4 编辑结果可在选谱页播放

### FR-07 音频
- FR-07-1 **按下轨道即演奏该音符原本音高**（读取谱面 MIDI）
- FR-07-2 使用 Web Audio 实时合成，音色为八音盒 / 古筝拨弦风格（快速起音、中等衰减）
- FR-07-3 半音（4 / 7）以 auto 音符自动发声，音量略低于玩家击打
- FR-07-4 同一轨道不同八度在方块亮度 / 描边上区分（高音提亮 + 白边，低音压暗）
- FR-07-5 全局唯一时间源为音频时钟，不使用系统时间

## 4. 非功能需求

| 编号 | 需求 | 实现方式 |
|---|---|---|
| NFR-01 | 主包 < 4MB | 当前主包 3.99MB（含 Cocos 引擎），无大体积音频 |
| NFR-02 | 不同屏幕尺寸不错位 | Canvas 尺寸 / 相机 orthoHeight 与 visibleSize 对齐，输入用相机反投影 |
| NFR-03 | 长时间游玩不抖动 | 音符节点对象池复用，避免运行时频繁创建 |
| NFR-04 | 可维护 | 纯代码构 UI（无 prefab），参数集中在 GameConfig |
| NFR-05 | 异常兜底 | 谱面非法数据过滤、音频初始化失败回退、存储失败降级 |

## 5. 范围外（本期不做）

- Hold / 长按 / 滑动音符
- 判定音效采样包（已改为按 MIDI 合成）
- 云端存档与排行榜
- 正式 AppID 上线与审核（需项目方提供资质）
- 多语言

## 6. 验收标准

| 验收项 | 判定依据 |
|---|---|
| 三个入口均可进入且可返回 | 模拟器点击验证 |
| 12 首曲目可完整播放至结算 | 选谱页数据 + 单测校验音符数 |
| 判定窗口准确 | 单测覆盖 ±40 / ±80 / ±120 边界 |
| 点击位置与反馈一致 | 修复后实测偏差 0 像素 |
| 难度筛选生效 | 模拟器三档筛选验证 |
| 宣传页内容完整、不重叠 | 单测行距校验 + 模拟器截图 |
| 类型检查零错误 | tsc --noEmit |
| 单元测试全绿 | 40 项通过 |
