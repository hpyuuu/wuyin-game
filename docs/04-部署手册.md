# 部署手册

> 项目：五音 · 五轨　版本：v1.0.0
> 适用对象：需要自行构建、预览、发布本项目的开发者

---

## 1. 环境要求

| 项 | 版本 / 说明 |
|---|---|
| Cocos Creator | 3.8.x（项目标注 3.8.8） |
| 微信开发者工具 | 稳定版（需登录） |
| Node.js | 仅用于本地类型检查/单测，运行游戏不需要 |
| 微信小游戏 AppID | **发布必需**；仅本地预览可用测试号 |
| 磁盘 | 预留 ≥ 2GB（library / temp / build） |

---

## 2. 拉取与打开项目

```bash
git clone https://github.com/hpyuuu/wuyin-game.git
```

1. 打开 **Cocos Dashboard → 项目 → 导入**
2. 选择仓库根目录（含 `package.json` 的那一层）
3. 用 Cocos Creator 3.8.x 打开，等待首次资源导入完成

---

## 3. 构建微信小游戏

1. 菜单 **项目 → 构建发布**
2. 平台选择 **微信小游戏**
3. 填写 **AppID**（若无，可先留空用测试号预览）
4. 关键选项：
   - 初始场景：`main.scene`
   - 设备方向：竖屏
   - 渲染管线：默认（无需改）
5. 点击 **构建**，产物输出到 `build/wechatgame/`（建议每次手动改名为 `wechatgame-0xx` 便于回溯）

> 项目已把 `build/` 加入 `.gitignore`，构建产物不入库。

**包体红线**：主包 ≤ 4MB。当前主包 3.99MB，若新增资源导致超限，请把大资源放分包或改用程序化生成。

---

## 4. 本地预览

### 4.1 开发者工具预览
1. 打开微信开发者工具 → **导入项目**
2. 目录选择 `build/wechatgame`
3. AppID 可填测试号或留空
4. 编译后即可在模拟器中操作

### 4.2 真机预览
- 开发者工具点击 **预览**，扫码在手机上打开
- 或在命令行生成二维码图片：

```bash
cli.bat preview --project <构建目录绝对路径> --qr-format image --qr-output preview-qr.png
```

---

## 5. 发布体验版

1. 使用**正式 AppID** 构建（个人主体也可，但需完成主体认证）
2. 开发者工具中点击 **上传**，填写版本号与备注（如 `1.0.0 首个体验版`）
3. 登录 [微信公众平台](https://mp.weixin.qq.com) → 版本管理 → 将开发版设为**体验版**
4. 添加体验成员后扫码试用
5. 验收通过后提交审核 → 审核通过后发布

> 本项目结项时**未执行正式发布**（无正式 AppID），代码与构建产物已就绪，按上述步骤即可上线。

---

## 6. 上线前检查清单

- [ ] 真机试听：按键音高是否与谱面一致
- [ ] 真机试听：半音（紫竹调 12.3s / 15.7s / 22.3s，彩云追月 5.8s）是否正常发声
- [ ] 手感校准：戴耳机跑 3 局，必要时调整 `GameConfig.globalOffsetMs`
- [ ] iOS 真机冒烟：三个页面、选谱、结算、返回
- [ ] 小屏机型（如 iPhone SE）宣传页无重叠
- [ ] 主包体积 < 4MB
- [ ] 隐私协议与用户信息声明（微信要求）

## 7. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| console 提示「未找到 BGM」 | 未放置 `assets/resources/audio/bgm.mp3` | 属正常降级，本项目不依赖 BGM |
| console 提示「五音采样加载失败」 | 采样解码失败 | 自动回退合成拨弦音，不影响功能 |
| 第一次点击没声音 | 浏览器/微信要求音频上下文需用户手势激活 | 首次点击后即恢复，属平台限制 |
| 音符判定总是偏早/偏晚 | 设备音频输出延迟 | 调整 `globalOffsetMs`（偏早调大、偏晚调小） |
| 构建后画面偏上、点击要往下按 | 旧版本 Canvas 未对齐 visibleSize | 已在 `_syncCanvasSize()` 修复，确认使用 v1.0.0 之后代码 |
| 主包超过 4MB | 新增了图片/音频 | 移入分包或改为程序化绘制 |

## 8. 版本回滚

```bash
git log --oneline            # 找到目标版本
git checkout v1.0.0          # 或指定 commit
```

构建产物可用 `build/wechatgame-0xx` 目录对应回滚，每个目录都是一次完整构建快照。

---

## 9. 本地开发校验

```bash
# 类型检查（使用 Cocos 自带 tsc）
node "<Cocos安装目录>/resources/app.asar.unpacked/node_modules/typescript/bin/tsc" --noEmit -p tsconfig.json

# 单元测试
cd tools/tests
node "<同上>/tsc" -p tsconfig.json
node test.js
```
