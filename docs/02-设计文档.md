# 设计文档（Architecture & Design）

> 项目：五音 · 五轨　版本：v1.0.0

---

## 1. 技术选型

| 项 | 选择 | 理由 |
|---|---|---|
| 引擎 | Cocos Creator 3.8.8 | 微信小游戏导出成熟，TypeScript 友好 |
| 语言 | TypeScript（strict 关闭，`noEmit` 校验） | 结构与类型提示 |
| 平台 | 微信小游戏（WebAudio） | 目标渠道 |
| UI | 纯代码构建（Node + Graphics + Label） | 无 prefab 依赖，便于程序化主题与布局 |
| 音频 | Web Audio API 实时合成 | 零音频素材，音高可随谱面变化 |
| 存储 | wx storage / localStorage | 自制谱持久化 |

## 2. 模块划分

```
GameEntry（入口 / 页面路由 / 输入分发）
├── core/
│   ├── GameConfig        全局参数（判定窗口、下落速度、音量、基础 MIDI）
│   ├── ChartTypes        谱面与判定数据结构
│   ├── ChartStore        内置谱生成、玩家谱增删改查、导入、加载
│   ├── AudioManager      音频上下文、时钟、合成发声、BGM（可选）
│   ├── NotePool          音符视图 + 按轨道分组对象池
│   └── GameMain          主循环：生成 → 位置 → 判定 → 计分 → 结算
└── ui/
    ├── Theme             五色、字体、颜色工具
    ├── Backdrop          深色网格背景
    ├── SceneBuilder      轨道 / 判定线 / 键位 / 光效，并输出 LayoutInfo
    ├── MainMenu          三张入口卡片
    ├── ChartSelect       选谱列表（分页 + 难度筛选）
    ├── ChartEditor       谱面编辑器（128 行网格）
    ├── FreePlay          自由弹奏（五根琴弦）
    ├── HUD               分数 / 连击 / 判定 / 结算
    ├── PromoPage         宣传内容页
    └── PressFeedback     统一按压反馈（缩放动画）
```

页面路由由 `GameEntry` 内的 `Screen` 状态机维护：`menu | select | editor | rhythm | free | promo`。

## 3. 数据模型

```ts
interface ChartNote {
  time: number;          // 毫秒，相对音频时钟原点
  lane: number;          // 0~4
  type: 'Tap';
  midi?: number;         // 精确音高，缺省回退到轨道基础音高
  auto?: boolean;        // 半音自动音符：不下落、不判定、到点发声
}

interface ChartData {
  name: string;
  bpm: number;
  offset: number;        // 整体偏移，正数延后
  notes: ChartNote[];
  meta?: ChartMeta;      // id / difficulty / builtin / noteCount
}
```

内置旋律谱用简谱字符串编码（`MelodyChartDef.grid`）：

- `1~5` 为宫商角徵羽，`4` / `7` 为半音（生成 auto 音符）
- `^` 升八度、`_` 降八度（只改 MIDI，不换轨道）
- `-` 空拍，`|` 与空格仅排版
- 格长 = `60000 / bpm × STEP_BEATS[difficulty]`（EASY 1 拍 / NORMAL 1/2 / HARD 1/4）

> 简谱数字到轨道的映射使用显式表 `{1:0, 2:1, 3:2, 5:3, 6:4}`。不可用 `indexOf`，否则 5 会错位、6 会被丢弃。

## 4. 时间线与坐标

- 唯一时间源：`AudioManager.getAudioTimeMs()`（基于 `AudioContext.currentTime`）
- 判定用时间：`now = getAudioTimeMs() - GameConfig.globalOffsetMs`
- 音符纵坐标：`y = judgeY + (note.time - now) × fallSpeed`
- 生成提前量：`(topY - judgeY) / fallSpeed + 260ms`
- 首音符前的 `leadInMs` 作为准备时间

---

## 5. 判定算法

1. `pressLane(lane)` 在同轨未判定音符中取 `|note.time - now|` 最小者
2. 若最小偏差 > `windows.good`（120ms），视为空气打，不消耗音符
3. 否则按偏差给出 PERFECT / GREAT / GOOD，播放命中动画并计分
4. 主循环中，`now - note.time > 120ms` 的音符自动判 MISS（下沉淡出后回收）

计分权重：PERFECT 1.0 / GREAT 0.65 / GOOD 0.3 / MISS 0；准确率为加权均值。

## 6. 音频架构

### 6.1 发声路径

```
onHit(lane, midi) ─┐
onAuto(midi)     ──┴→ AudioManager.playNote(midi, velocity)
                        → freq = 440 × 2^((midi-69)/12)
                        → OscillatorNode(setPeriodicWave) + GainNode(ADSR)
                        → master → destination
```

- 音色：自定义周期波（基频 + 逐次衰减的 7 个泛音），模拟八音盒 / 古筝拨弦
- 包络：4ms 起音 → 140ms 降至 32% → 1.1s 衰减至静音
- `onAuto` 音量系数 0.7，避免盖过玩家击打
- 每次发声在 `onended` 中 `disconnect()`，防止音频图节点泄漏

### 6.2 自由弹奏

`playPluck(lane)` 优先使用钢琴采样（C4 / F#4 / A4 变调，最多跨 3 个半音），采样不可用时回退程序化拨弦缓冲。

### 6.3 时钟

- `startClock()` 记录 `_clockOrigin = ctx.currentTime`
- 可选 BGM 缺失时用静音保活振荡器维持时钟推进

## 7. 输入与坐标换算

历史问题：Canvas 中心停在设计分辨率中心，而输入按可见高度换算，导致反馈位置比实际点击点高约 139 设计像素。

现方案：

1. `_syncCanvasSize()`：Canvas 尺寸、位置、相机 `orthoHeight` 与 `visibleSize` 对齐
2. `_toLocal(event)`：`uiCamera.screenToWorld()` 后用 `convertToNodeSpaceAR` 转节点坐标
3. 命中判定统一走 `UITransform.hitTest`（引擎保证「画在哪就点在哪」）

按压反馈：`PressFeedback` 统一 0.96 缩放，按下 80ms、抬起 140ms、滑动取消阈值 14px。

---

## 8. 对象池

`NotePool` 按轨道分池，`acquire(lane)` 取出即用（`reset()` 复位颜色与透明度），`release(view)` 前停动画并隐藏。包含越界归零与重复归还防御。

八度视觉：`setPitch(midi, base)` 计算 `round((midi-base)/12)`，高音提亮 + 白边 + 强光晕，低音压暗。

## 9. 关键参数（GameConfig）

| 参数 | 值 | 说明 |
|---|---|---|
| designWidth / designHeight | 720 / 1280 | 设计分辨率 |
| laneCount | 5 | 轨道数 |
| noteWidth / noteHeight | 58 / 58 | 音符尺寸 |
| fallSpeed | 0.62 px/ms | 下落速度 |
| windows | 40 / 80 / 120 ms | 判定窗口 |
| endDelayMs | 1400 | 结算延迟 |
| leadInMs | 2000 | 前奏 |
| globalOffsetMs | 0 | 真机手感校准 |
| hitVolume | 0.55 | 击打音量 |
| laneBaseMidi | [60,62,64,67,69] | 五轨基础音高 |

## 10. 布局自适应

- `computeLayout(visibleSize, topInset)` 输出轨道宽、判定线 Y、轨道顶部 Y
- 保护：`topY = max(rawTopY, judgeY + 240)`，极端矮屏下轨道不反向
- 宣传页文案段间距按可用高度在 14~46px 间自适应，屏高 < 1300 时正文行距收紧到 22
